## 🚀 QUICK START

### **1. Install**
```bash
git clone https://github.com/NIKITH-14/Maya-ai.git
cd Maya-ai
python -m venv .venv310
.venv310\Scripts\activate
pip install -r requirements.txt
```

### **2. Configure**
```bash
set GEMINI_API_KEY=your_key_here
```

### **3. Run**
```bash
# Console
python maya.py

# GUI
start_maya_gui.bat
```
